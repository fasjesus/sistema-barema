\chapter{Desafios Científicos e Técnicos}
O desafio não reside na complexidade da interface, mas na implementação de um orquestrador inteligente - que diferente de uma automação simples, utiliza dados em tempo real e, frequentemente, IA para coordenar múltiplos sistemas, serviços e pessoas de forma fluida - muito importante para aplicação visto que o sistema deve lidar com a manipulação de PDF em tempo real. A solução deve ser simples para o usuário, mas robusta o suficiente para garantir a integridade dos dados.
